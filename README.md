# Admin Dashboard

A modern, responsive admin dashboard built with HTML, CSS, and JavaScript.

## 🚀 Live Demo

https://abdul306.github.io/admin-dashboard/

## ✨ Features

- Responsive admin dashboard
- Interactive sidebar navigation
- Dark and light mode
- Persistent theme preference
- Live date and time
- Animated dashboard statistics
- Interactive sales chart
- Order search functionality
- Notification dropdown
- Customer statistics
- Product overview
- Recent orders table
- Settings section
- Mobile-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 📱 Responsive Design

The dashboard is designed to work across:

- Desktop
- Tablet
- Mobile
